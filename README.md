# Operaciones-Arreglos-Matrices-Java
Proyecto desarrollado en Java aplicando programación orientada a objetos para resolver operaciones con arreglos, vectores, matrices y registros de calificaciones.
# Operaciones con Arreglos y Matrices en Java

## Descripción
Proyecto desarrollado en Java utilizando programación orientada a objetos para realizar operaciones con vectores, arreglos y matrices, así como el procesamiento de calificaciones de estudiantes.

## Objetivo
Aplicar los conocimientos de programación Java para resolver problemas mediante clases, objetos, métodos y estructuras de datos.

## Funcionalidades

### 1. Distancia respecto al valor máximo
- Registra cinco números enteros.
- Identifica el número mayor.
- Calcula la distancia entre cada número y el valor máximo.

### 2. Operaciones con vectores
- Invierte los elementos de un vector.
- Suma un valor a sus elementos.
- Cuenta las apariciones de un número.
- Identifica los números pares.
- Calcula la suma total.

### 3. Procesamiento de calificaciones
- Trabaja con las notas de 25 estudiantes.
- Procesa tres calificaciones por estudiante.
- Calcula los promedios de las notas.

### 4. Operaciones con matrices
- Trabaja con una matriz de 4 x 4.
- Realiza el intercambio de filas.
